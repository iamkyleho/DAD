# 🎂 우리 아빠 생일 케이크

아빠를 위한 작은 생일 파티. 화면의 케이크를 누르면 촛불이 꺼지고, 폭죽과 색종이가 터지며 생일 축하 음악이 재생됩니다.

- 금박과 `DAD` 장식을 담은 SVG 케이크
- 피아노·뮤직박스 음색으로 편곡한 약 21초의 생일 축하곡
- 휴대폰과 데스크톱 화면 지원
- 움직임 줄이기 설정을 존중하는 축하 효과

## 실행

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다. 별도의 설치나 빌드 과정이 필요하지 않습니다.

케이크를 다시 누르면 처음부터 재생됩니다. `Escape` 키를 누르거나 다른 탭으로 이동하면 음악과 효과가 멈춥니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 생일 케이크 화면 |
| `styles.css` | 조명, 촛불, 반응형 스타일 |
| `app.js` | 클릭 동작, 폭죽, 색종이 효과 |
| `audio.js` | Web Audio 기반 음악과 효과음 |
| `assets/cake.svg` | 케이크 일러스트 |

모든 시각·음악 자산은 저장소에 포함되거나 브라우저에서 생성됩니다. 외부 라이브러리나 네트워크 연결 없이 실행할 수 있습니다.
